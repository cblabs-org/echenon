# WO-15.1: Portal Cleanup & Tab Restructure

> **Parent PR:** [PR-15 PROJECT.md](../PROJECT.md)
> **Branch:** `pr-15-portal-ride/wo1-portal-cleanup` (base: `feat/pr-15-portal-ride`)

---

## 1. Objective

Remove the default App tab, strip signal-logger diagnostic content from the production `echenon-dashboard.js`, remove top-level Session and Upload Services tab registrations from `SessionOverlay`, remove separate Calibration/Recalibration top-level tab registrations from `EchenonModule`, and rewrite the Echenon dashboard tab to show a clean device status summary with a prominent "Open Ride Page →" button.

After this WO, the portal bottom nav should show exactly **6 top-level tabs** in order:
1. WiFi (10)
2. Bluetooth (15)
3. Echenon (50)
4. Setup (60) — registered in WO-15.2
5. Security (5) — framework Security tab
6. System (framework aggregate)

**Note:** The Security and System tabs are framework-managed. This WO focuses on removing surplus consumer-registered tabs and cleaning the Echenon tab. The "Setup" tab will be registered by WO-15.2 — do NOT register it here.
